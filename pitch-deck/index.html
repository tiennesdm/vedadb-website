14 Native AI SQL Functions

Run AI directly in SQL queries. No external APIs. No network latency. No per-token costs.

EMBED() AI_SIMILARITY() AI_CLASSIFY() AI_SENTIMENT() AI_KEYWORDS() AI_REDACT() HYBRID_RANK() VECTOR_DISTANCE() RECOMMEND_VECTOR_INDEX() DOT() VECTOR_NORM() L2_NORMALIZE() DP_NOISE_LAPLACE() DP_NOISE_GAUSSIAN()

Use Cases

  • Semantic Search: SELECT * FROM docs ORDER BY AI_SIMILARITY(content, EMBED('query')) DESC
  • Auto-Classification: SELECT AI_CLASSIFY(support_ticket, 'urgency') FROM tickets
  • Privacy-Preserving Analytics: SELECT AVG(salary + DP_NOISE_LAPLACE(10000)) FROM employees
  • Hybrid Search: SELECT * FROM products WHERE HYBRID_RANK(text_col, vector_col, 'query') > 0.8
