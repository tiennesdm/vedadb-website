## 7 Engines, 1 System

| Engine | Purpose | Key Features |
|--------|---------|-------------|
| **SQL** | ACID Transactions | Complex joins, window functions, subqueries |
| **Vector** | AI / RAG Search | HNSW indexing, cosine similarity, embeddings |
| **Graph** | Relationships | Cypher queries, PageRank, community detection |
| **Document** | Flexible JSON | Schema-free, nested queries, aggregation |
| **Cache** | Speed | In-memory, LRU eviction, TTL support |
| **Search** | Full-Text | Fuzzy matching, faceted search, relevance scoring |
| **Time Series** | Metrics | Columnar compression, rollups, retention policies |

## Built-In AI

- **NL2SQL** - Ask in English, get SQL results (Anthropic Claude)
- **AutoTuner** - Bayesian Optimization with Gaussian Process (40% latency reduction)
- **Semantic Cache** - LRU embedding deduplication (40-80% cost savings)
- **14 Native AI SQL Functions:** `EMBED()`, `AI_SIMILARITY()`, `AI_CLASSIFY()`, `AI_SENTIMENT()`, `AI_KEYWORDS()`, `AI_REDACT()`, `HYBRID_RANK()`, `VECTOR_DISTANCE()`, `RECOMMEND_VECTOR_INDEX()`, `DOT()`, `VECTOR_NORM()`, `L2_NORMALIZE()`, `DP_NOISE_LAPLACE()`, `DP_NOISE_GAUSSIAN()`
