## What is VedaDB?

VedaDB is a unified multi-model database that combines **7 specialized engines** into a single, coherent system:

| Engine | Purpose | Status |
|--------|---------|--------|
| **SQL** | Relational data, ACID transactions | ✅ Built |
| **Vector** | Similarity search, AI/RAG | ✅ Built |
| **Graph** | Relationships, recommendations | ✅ Built |
| **Document** | JSON-native, flexible schema | ✅ Built |
| **Cache** | Sub-millisecond reads | ✅ Built |
| **Search** | Full-text, fuzzy matching | ✅ Built |
| **Time Series** | IoT, monitoring | ✅ Built |
